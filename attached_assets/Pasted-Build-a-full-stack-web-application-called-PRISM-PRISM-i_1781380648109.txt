Build a full-stack web application called PRISM.

PRISM is an AI decision intelligence system that helps users make better decisions by showing multiple AI perspectives (like a debate between different thinking styles).

This is NOT a chatbot. It is a structured decision analysis engine.

--------------------------------------------------
🧠 CORE FUNCTION
--------------------------------------------------

User enters a decision or question.

Example:
"Should I start a startup or focus on university?"

The system generates 4 AI perspectives:

1. Contrarian → finds risks, flaws, and failure cases
2. Expansionist → focuses on opportunities and upside
3. Executionist → gives practical step-by-step plan
4. Analyst → balanced logical tradeoff analysis

Then the system produces:
- structured responses per persona
- final synthesized verdict
- confidence score (0–100)

--------------------------------------------------
🧠 AI LOGIC (IMPORTANT)
--------------------------------------------------

When user submits a question:

Call AI 4 times in parallel using Promise.all:
- contrarian prompt
- expansionist prompt
- executionist prompt
- analyst prompt

Each must use a different system prompt.

Return structured JSON:

{
  question: string,
  personas: {
    contrarian: string,
    expansionist: string,
    executionist: string,
    analyst: string
  },
  verdict: string,
  confidence: number
}

--------------------------------------------------
🧩 PERSONA SYSTEM PROMPTS (/lib/personas.ts)
--------------------------------------------------

Contrarian:
You are a critical thinker. Always challenge assumptions, highlight risks, and explain why ideas might fail.

Expansionist:
You are an optimistic strategist. Focus on opportunities, scaling, growth, and big-picture upside.

Executionist:
You are a practical builder. Give step-by-step actionable plans and implementation details.

Analyst:
You are a neutral analyst. Compare tradeoffs logically and provide balanced reasoning.

IMPORTANT:
Do NOT roleplay humans. You are simulating decision-making frameworks.
